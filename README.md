# 🎓 UniGuide KZ — EdTech-платформа для абитуриентов Казахстана

> **«Все необходимое для поступления в университеты Казахстана — в одном месте.»**

UniGuide KZ — современный цифровой сервис, спроектированный для школьников 9–11 классов, выпускников, абитуриентов и их родителей. Платформа помогает находить, анализировать и сравнивать университеты Казахстана, проверять шансы на грант по баллам ЕНТ и читать честные отзывы студентов.

---

## 📌 Основные возможности

* **Интерактивный каталог вузов**: поиск в реальном времени, сортировка по рейтингу и программам, фильтрация по городам Казахстана (Астана, Алматы, Караганда).
* **Честные отзывы и оценки**: модальное окно каждого университета с разбором плюсов/минусов, стоимостью обучения, условиями грантов и формой добавления собственного отзыва с сохранением в браузере.
* **Таблица сравнения (2–3 вуза)**: наглядное сопоставление университетов по ключевым критериям без предвзятости (форма собственности, гранты, стоимость, рейтинг).
* **Калькулятор шансов поступления**: экспресс-оценка вероятности получения государственного или университетского гранта на основе баллов ЕНТ.
* **Тест на профориентацию**: короткий интерактивный опросник для определения подходящей карьерной траектории.
* **Избранное**: сохранение понравившихся учебных заведений в `localStorage` без потери данных при перезагрузке.
* **Демо-админ панель**: панель управления базой университетов с возможностью удаления и сброса данных к эталонным.

---

## 🛠 Технологический стек

* **Frontend**: HTML5, Modern Vanilla JavaScript (ES6+ Modules)
* **Стилизация**: [Tailwind CSS CDN](https://tailwindcss.com/) (кастомная палитра Indigo/Brand, адаптивная сетка под Mobile/Desktop)
* **Иконки**: [Lucide Icons](https://lucide.dev/)
* **Хранилище данных**: Web Storage API (`localStorage`) для персистентности отзывов, сравнений и избранного без необходимости стороннего бэкенда при демонстрации
* **Хостинг**: [GitHub Pages](https://pages.github.com/)
